# Customer Relationship Manager

## Project Description

The Customer Relationship Manager (CRM) is a web-based application designed to help businesses manage their interactions with current and potential customers. It provides an easy-to-use interface for logging in and out, creating, updating, and deleting customer records. The project aims to streamline customer management processes and improve business efficiency by organizing customer data in one place.

## Installation Instructions

To get started with the CRM, follow these simple steps:

1. **Clone the repository:**

   ```bash
   git clone <repository_url>
   ```

2. **Navigate to the project directory:**

   ```bash
   cd customer-relationship-manager
   ```

3. **Install the required dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Run the server:**

   ```bash
   python manage.py runserver
   ```

5. **Access the application:**

   Open your web browser and navigate to `http://127.0.0.1:8000/`.

## Usage Instructions

Using the CRM is straightforward and user-friendly. The application provides the following basic functionalities:

- **Login:** Authenticate yourself to access the CRM.
- **Logout:** Securely exit the CRM.
- **Create a Record:** Add a new customer record to the database.
- **View Records:** Browse through the list of existing customer records.
- **Update a Record:** Modify the details of an existing customer record.
- **Delete a Record:** Remove a customer record from the database.

## Technologies Used

The CRM is built using the following technologies:

- **Backend:** Django
- **Frontend:** Bootstrap CSS, a bit of JavaScript
